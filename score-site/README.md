# موقع نتائج المباريات (بدون بث)

## التشغيل محليًا
```bash
cd score-site
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الانتقال إلى بيانات حقيقية
1. احصل على مفتاح مجاني من football-data.org.
2. لا تضع المفتاح في كود الواجهة. أنشئ خادمًا صغيرًا (Node) يحمل المفتاح في `.env` ويستدعي الـAPI ويخزّن النتيجة مؤقتًا.
3. عدّل الدالة `loadMatches()` في `app.js` لتجلب من خادمك، وحوّل الشكل إلى نفس حقول `data/matches.json`.
